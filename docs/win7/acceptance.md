# Win7 验收矩阵

目标范围使用 [技术实施方案](../../GenOffice_Win7_Implementation_Plan.md) 的 F01–F13。工作项及其当前状态由 [实施台账](IMPLEMENTATION_STATUS.md) 维护。

## 对照环境

| 环境 | 应用和系统                             | 回答的问题                  |
| ---- | -------------------------------------- | --------------------------- |
| A    | 同基线的原版，现代 Windows             | 上游原始行为和已知问题      |
| B    | Win7 profile，现代 Windows             | 裁剪正确性和非 PDF 功能差异 |
| C    | 与 B 对应的 Win7 profile，Win7 SP1 x64 | 目标平台的运行时和行为差异  |

对照采用同一 fixture 哈希、字体、DPI、渲染比例和操作脚本。记录安装包、运行时 SHA-256、OS 补丁、显卡与驱动以及兼容层配置。对非随机功能比对输出和错误语义，对模型链路使用固定响应的 mock，真实模型联调单独记录。PoC 与最终发布验收各自记录证据。

## 运行时门禁

| ID   | 操作                                            | 达标条件及证据                                                                       |
| ---- | ----------------------------------------------- | ------------------------------------------------------------------------------------ |
| RT01 | 启动锁定的运行时，分析 PE 导入和加载结果        | 版本吻合，启动无加载器错误。保留日志、哈希及必要的缺失 API 诊断。                    |
| RT02 | 文件操作、加密、SQLite、子进程、内网 TLS 和 SSE | 文件同步写入和 SQLite 查询正确，子进程正常回收，TLS 校验、流中断与重连行为符合预期。 |
| RT03 | 建立至少五个 View，切换、销毁、重建并打开弹窗   | 各 View 保持正确文档及焦点，切换和释放可复现，进程树符合预期。                       |
| RT04 | 确认真实 Renderer 权限，执行受控 IPC 和负面用例 | 隔离和沙箱生效，允许的 IPC 返回预期结果，越权调用被拒绝。                            |
| RT05 | Canvas 2D、WASM、Worker、字体、中文输入         | 有可核对的渲染和输入输出，无崩溃或丢字。                                             |
| RT06 | 隐藏窗口打印后由 PDFium 栅格化，并执行失败用例  | PNG 有效，真实 Office 样本可视，内部 PDF 清理，外部 PDF 输出被拒绝。                 |
| RT07 | 对同一样本运行 GPU 和可用的软件渲染路径         | 目标硬件至少一条路径稳定，采用回退时记录保真和性能数据。                             |
| RT08 | 文件对话框、拖放、剪贴板、快捷键、DPI           | 在目标终端配置逐项记录预期行为、输入与输出。                                         |
| RT09 | 反复启停并模拟异常退出及重新启动                | 进程可回收，资源无持续增长，应用恢复后可继续工作。                                   |

## 记录与发布判定

每条验收记录至少包含 `testId`、子用例、A/B/C、profile、上游与应用版本、运行时 SHA-256、OS、样本 SHA-256、预期、实测、状态、证据路径和缺陷引用。状态使用 `pass`、`fail`、`blocked`、`not-run`。应用版本和测试环境按证据覆盖的实际范围填写。渲染 PoC 辅助记录内部 PNG 链路子用例，T08 完整验收还需真实样本视觉比对、裁图、B/C 结果与故障场景。

正式发布要求 C 组适用验收项及 A/B/C 对照全部通过，高严重度和阻断缺陷为零。性能、长时压力和样本数量按 [实施方案第 11 节](../../GenOffice_Win7_Implementation_Plan.md#11-验收设计与证据要求) 的建议使用目标终端数据校准。公开仓库中的证据使用公开或合成样本，并移除本机账号路径及凭据。
